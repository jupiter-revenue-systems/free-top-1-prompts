# The Prompt Behind the Work

**You write prompts that get finished work back, not a first draft.**

Most people type one line and get average work. This shows how I write the long, exact prompts that run my builds, with real examples, and gives you a skill that interviews you and writes a top 1% prompt for any job.

I'm Ekai Stone. I've been a business owner for 17 years, and I run my business solo with AI agents doing most of the hands-on work. These are the same shapes I use every day.

## Who it's for

- You ask AI for something and get generic work back.
- You've heard "write better prompts" and nobody showed you what that looks like.
- You'd like the AI to ask you the right questions, so you don't have to guess what it needs.

Works in Claude. Most of it works in ChatGPT too.

## How to use it

1. Read `GUIDE.md`. It takes about 10 minutes.
2. Pick one real job you need done this week. Keep it small.
3. Install the skill with `INSTALL.md`, or paste `templates/05-interview-me.md` into a new chat.
4. Say "architect a prompt" and answer the questions one at a time.
5. Paste the master prompt it gives you into a NEW chat and let it work.
6. If the result misses, use `templates/04-fix-it.md`. Don't say "make it better".

## What it doesn't do

- It writes one prompt for one job. It doesn't remember your business. Your next chat starts from zero.
- These are starter templates. The full master prompts behind my builds are longer and tied to my own systems, so they aren't in here.
- It writes the brief. It doesn't check the finished work for you.
- It won't pick your strategy. If you're not sure what to build, a better prompt gets you a clearer version of the wrong thing.
